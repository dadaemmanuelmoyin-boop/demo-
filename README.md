# Receipt Lab

Single-file dark-mode receipt and activity screen prototyping tool for UI/UX work.

- Tap the ₿ logo to edit fields, tap Proceed for the activity screen
- Amount, BTC rate and fees recalculate crypto and total (sats)
- Presets are stored in the browser (localStorage)
- A [PROTOTYPE PREVIEW] badge is always shown by design

Open `index.html` or host it with GitHub Pages (Settings > Pages > deploy from `main`).
